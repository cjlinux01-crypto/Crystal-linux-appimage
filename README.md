# Crystal Linux para Gear Lever

Este repositório disponibiliza recursos e aplicações do Crystal Linux empacotados no formato AppImage, prontos para gestão e integração no seu sistema através do [Gear Lever](https://github.com/miamipm/gear-lever).

---

## O que é o Gear Lever?
O Gear Lever é uma ferramenta para Linux desenhada para gerir ficheiros AppImage: organiza os executáveis, integra ícones ao ambiente de trabalho e adiciona entradas ao lançador de aplicações.

---

## Como descarregar
1. Aceda à secção de **Releases** no menu lateral direito deste repositório.
2. Localize a versão pretendida e descarregue o ficheiro `.AppImage`.

---

## Como usar com o Gear Lever
1. Abra o **Gear Lever** no seu sistema.
2. Arraste e solte o ficheiro `.AppImage` descarregado para a interface do Gear Lever (ou use a opção de importar).
3. O Gear Lever tratará automaticamente das permissões e do atalho no menu.

---
